# Security Policy

*[Deutsche Version](SECURITY.md)*

hoerbox-feeder is meant to run on your own, trusted LAN (see the note in
`docker-compose.yml`: don't expose it directly to the internet, no built-in
auth). Still, if you find a security vulnerability, we'd appreciate a
responsible report.

## Reporting a vulnerability

**Please don't report it as a public GitHub issue.** Instead, reach out
directly to:

**kasati@kasati.net**

Please include, where possible:
- A short description of the issue and its potential impact
- Steps to reproduce
- The affected version/commit

We'll try to respond promptly. Non-security bugs should still go through
regular [GitHub Issues](https://github.com/kasati111/hoerbox-feeder/issues).

## Supported versions

Only the latest state of `main` is currently maintained.
