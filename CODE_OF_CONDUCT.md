# Verhaltenskodex

Dieses Projekt richtet sich unter anderem an Eltern, die für ihre Kinder
Inhalte einrichten – ein freundlicher, respektvoller Umgangston ist uns
entsprechend wichtig.

## Kurzfassung

- Sei respektvoll, auch bei Meinungsverschiedenheiten.
- Konstruktive Kritik ist willkommen, persönliche Angriffe nicht.
- Belästigung, Diskriminierung oder beleidigendes Verhalten jeder Art wird
  nicht toleriert.

## Durchsetzung

Verstöße können über GitHub Issues oder direkt bei den Maintainern gemeldet
werden. Maintainer können Kommentare entfernen, Diskussionen sperren oder
Mitwirkende bei wiederholten Verstößen ausschließen.

Angelehnt an den [Contributor Covenant](https://www.contributor-covenant.org/).
